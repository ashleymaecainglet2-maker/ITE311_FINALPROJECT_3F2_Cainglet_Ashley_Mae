Project Title: FitLedger: Gym Management System
Student Name: Adrian Viernes
Course and Section: BSIT III-F2
Project Description: A streamlined B2B SaaS administrative dashboard designed for independent gyms in the Philippines. It replaces manual logbooks with a centralized platform featuring QR code check-ins, automated background checks for active subscriptions, and GCash payment integration.
Technologies Used: Laravel 11, Filament PHP v3, MySQL, PayMongo API, Tailwind CSS.
